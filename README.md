# SoundClash - API

SoundClash is a Top Trumps-style game featuring music artists. This project was developed as part of a pair programming hackathon completed within 24 hours.

## About the Game

In SoundClash, players compare stats of music artists to determine the winner, similar to the classic Top Trumps card game. The game is designed to be fun, fast-paced, and engaging for music enthusiasts.

## Hackathon Details

- **Duration**: 24 hours
- **Approach**: Pair programming
- **Goal**: Build a functional and interactive game prototype within the time limit.

## Tech Stack

- **Frontend**: React with Vite
- **Styling**: Sass
- **Linting**: ESLint with React-specific rules

## How to Run the Project

### Run Locally

Clone the project

```bash
  git clone https://github.com/RobellA99/SoundClash-API.git
```

Go to the project directory

```bash
  cd soundclash-api
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run dev
```
